# pain-point

## Purpose
Keep WatchMarks focused on its core pain point:
"Save once, retrieve instantly, act without friction."

## Trigger
Use this skill whenever planning or implementing:
1. UI/UX changes
2. New product features
3. Search, dashboard, share-to-save, or recommendation behavior

## Product Truth
WatchMarks is a personal content memory and recall system.
It is not a recommender-first browsing app.

## Rules
1. Saved results always come before recommendations.
2. Saved and recommended content are visually separated.
3. Capture flows minimize manual input.
4. Dashboard entry prioritizes intent ("what do you feel like?").
5. Every surfaced result has an immediate action path.

## Feature Gate
Before shipping, verify:
1. Capture friction is reduced or unchanged.
2. Retrieval speed is improved or unchanged.
3. Cognitive load is reduced (fewer decisions/taps).
4. The change strengthens saved-first behavior.

If 3 or more checks fail, redesign before merge.

## Preferred Copy
1. "From your list"
2. "Not in your list"
3. "Save from anywhere"
4. "Find what you already saved"
